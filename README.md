# CampusVoice（程园小二）

> 上海工程技术大学校学生会权益生活部 · 权益工作小组

面向同学的线上权益服务入口：通过微信小程序收集同学的意见、建议、咨询与投诉，由权益工作小组分类流转、跟进处理；相关职能部门老师可在线更新进度并回复，同学可查询办理结果。

当前为双端高保真交互 Demo，依据 `REQUIREMENTS.md` 实现：

- 微信小程序学生端：提交诉求、生成编号、查看进度与时间线、满意度评价、公开反馈筛选与脱敏详情。
- Web 管理端：历史数据看板、诉求受理、办理流转、公开审核和操作日志。
- 后端（规划中）：接口与数据模型设计见 `backend/DESIGN.md`。

## 运行方式

- 微信小程序学生端：提交诉求、生成编号、查看进度与时间线、满意度评价、公开反馈筛选与脱敏详情。
- Web 管理端：历史数据看板、诉求受理、办理流转、公开审核和操作日志。

## 运行方式

### 微信小程序

使用微信开发者工具打开项目根目录。项目配置中的 `miniprogramRoot` 已指向 `miniprogram/`。

小程序使用本地 Mock 与微信本地存储，不需要启动后端。

### Web 管理端

直接在浏览器打开 `admin-web/index.html`。页面使用原生 HTML、CSS 和 JavaScript，不需要安装依赖或启动服务器。

## 数据说明

- 管理端看板的四期汇总数据来自用户提供的“程园小二”交接周报，周期为 2026-06-12 至 2026-07-16。
- 管理端工单、流转记录与公开审核内容为脱敏模拟数据，用于展示新系统能力。
- 小程序公开案例为模拟脱敏案例，不是历史真实投诉。
